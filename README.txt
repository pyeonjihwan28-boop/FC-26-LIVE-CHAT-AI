FC 26 라이브 채팅

[처음 한 번]
1. python.org에서 Python 3.11 또는 3.12 설치 ("Add python.exe to PATH" 체크)
2. 이 폴더의 install.bat (설치) 더블클릭 (몇 GB를 내려받으니 시간이 걸립니다)

[그다음부터]
FC 26만 실행하면 됩니다.
- 게임이 켜지면 오른쪽(모니터가 2개면 두 번째 모니터)에 채팅 창이 뜨고,
  선발 명단을 설정해 두었다면 화면 왼쪽 아래에 명단이 뜹니다.
- 경기가 시작되면 채팅 창 가운데의 [킥오프] 버튼을 누르세요. 그때부터 채팅이 나옵니다.
  (오른쪽 클릭 메뉴의 '채팅 멈추기'로 다시 킥오프 전으로 돌릴 수 있습니다)
- 채팅 속도는 시청자 수에 맞춰 자동으로 정해지고, 골 같은 큰 장면 직후에는 채팅이 몰립니다.
- 게임을 끄면 창도 사라집니다.
- FC 26 화면 설정에서 '테두리 없는 창' 모드를 쓰면 게임 위에 창이 보입니다.

[설정] 채팅 창에서 오른쪽 클릭
- 선발 명단 설정: 팀별 포메이션, 등번호, 이름, 교체 선수, 유니폼 색
- 선수 기록 넣기: 받아쓰기가 놓친 골·카드·교체를 직접 표시
- 팀 직접 정하기: 자동으로 찾은 팀이 틀렸을 때
- 채팅 분위기: 기본 / 응원 폭발 / 까칠 / 훈훈 / 훈수 / 엉뚱, 그리고 분위기 세기 0~10
- 내 채팅 이름: 입력칸에 쓴 내 채팅이 뜨는 이름 (기본 '방장')
- 채팅 캡처 저장: 최근 채팅 12줄을 그림으로 clips 폴더에 저장
- 게임 위에 해설 자막 띄우기: 받아쓴 해설을 게임 화면 아래쪽에 영화 자막처럼 표시 (기본 켜짐)
- 채팅 창 아래에 해설 자막 보기: 받아쓴 해설을 채팅 창 아래에 표시
- 받아쓴 해설을 파일로 저장: transcripts 폴더에 경기마다 .txt 파일로 (시각·경기 시간과 함께)

[내가 채팅 치기]
채팅 창 아래 입력칸에 쓰고 Enter를 누르면 내 이름(기본 '방장')이 노란색으로 뜨고,
시청자 여럿이 그 말에 바로 반응합니다. 최근 채팅의 닉네임을 넣어 부르면 그 사람이 먼저 대답합니다.
(킥오프 전에는 내 채팅만 뜨고 반응은 없습니다)

[해설 자막]
- 게임 소리를 이 PC 안에서 받아써서 화면 아래쪽 가운데(선발 명단·채팅 창과 겹치지 않는 곳)에 띄웁니다.
- 해설자가 말하는 중에는 노란 미리보기 자막이 먼저 뜨고, 문장이 끝나면 흰 자막으로 바뀝니다.
  미리보기는 그래픽카드로 받아쓸 때만 켜집니다 (CPU면 최종 자막이 늦어지므로).
- 자막 창은 마우스 클릭이 뒤의 게임으로 통과하고, 5초 동안 조용하면 사라집니다.

[팀·선발 명단·골은 게임 화면으로]
- 팀: 스코어보드 약칭(VIL, BAR 등)으로 찾고, 못 찾으면 화면 위쪽(스코어보드·엠블럼)을 AI가 보고 찾습니다.
- 선발 명단: 경기 중 일시정지해서 "선발 라인업" 화면(양쪽 선수 목록)을 띄우면 두 팀 명단을 읽습니다.
  다시 띄웠을 때 바뀐 자리는 교체로 표시합니다.
- 포메이션: 내 팀은 "팀 관리 → 스쿼드" 화면을 띄우면 포메이션과 선수 자리를 읽습니다.
  상대 팀은 AI가 선수 포지션을 보고 정합니다.
- 골·점수: 스코어보드 점수가 바뀔 때만 셉니다 (해설로는 세지 않음).
- 득점자: 화면 아래 선수 표시(이름·등번호)로 정합니다. 골 직전에 표시된 그 팀 선수,
  또는 골 뒤 화면 아래에 나오는 득점자 이름. 해설로는 정하지 않습니다.
- 선수 이름은 한국어·영어 어느 쪽으로 나와도 같은 선수로 알아봅니다 (야말 = Yamal).

[해설 반응]
해설 한 문장이 들어올 때마다 이 PC의 AI(Ollama)가 어떤 장면인지(골, 선방, 슈팅, 파울, 교체…),
어느 팀·어느 선수 이야기인지 판단하고, 채팅을 한 줄씩 바로 만들어 띄웁니다.
점수·득점자는 게임 화면으로만 정하고, 카드·교체 표시는 AI 판단을 따릅니다.
AI가 꺼져 있으면 해설에는 반응하지 않고 평소 잡담만 나옵니다.

[자동으로 정해지는 것]
- 채팅 속도: 시청자 수에 맞춰, 큰 장면 직후엔 몰리고 하프타임엔 뜸하고 후반 막판엔 빨라짐
- 시청자끼리 대화: 최근 채팅이 쌓이면 가끔 서로 @닉네임으로 불러 맞장구·반박 (AI가 켜져 있을 때)
- 시청자 수: 경기가 진행될수록 늘고, 골 때 확 늘고, 하프타임엔 빠졌다 돌아오고, 끝나면 서서히 나감
- 중립 팬 비율: 두 팀 인기에 맞춰
- 팀 팬 수: 팀이 정해지면 이 PC의 AI(Ollama)에게 물어봄 (공식 SNS 팔로워 합계 기준).
  팀마다 30일 동안 기억해서 다시 묻지 않음. AI가 없거나 실패하면 내장 표를 쓰고,
  '팀 직접 정하기'에서 팬 수를 넣으면 그 값이 우선.
- 채팅 글자 크기: 채팅 창 폭에 맞춰 (창을 넓히면 커짐)
- 선발 명단 크기·배치: 모니터 해상도에 맞춰, 명단을 넣은 팀만 표시
- 초록 배경(OBS 크로마 키): OBS가 켜져 있으면 자동으로
- 채팅·선수 기록 지우기: 킥오프를 누르면 새 경기로 보고 지움
- 킥오프 전으로 돌아가기: 경기 종료 2분 뒤, 또는 스코어보드의 팀·시간이 새 경기로 바뀌면

[선발 명단 표시]
- 초록 이름: 교체로 나가거나 들어온 선수
- 축구공: 득점한 선수 (유니폼 위)
- 노란/빨간 네모: 경고/퇴장
- 경기장 아래: 교체로 들어온 선수

[미리보기] preview.bat - 게임 없이 화면이 어떻게 뜨는지 봅니다.
[끄기] stop.bat - 채팅을 끄고 자동 실행을 해제합니다.

[설정 파일] fc26_chat_config.json
- korean_players: 팀별 한국 선수 (2025-26 시즌 기준 추정이라 틀리면 고치세요)
- scoreboard_region: 스코어보드 위치(화면 비율). 점수를 못 읽으면 조정하세요.
- ollama_model: 해설 판단·채팅에 쓰는 AI 모델 (기본 exaone3.5:7.8b, 한국어 특화).
  없으면 설치된 것 중 gemma3:12b → qwen2.5:7b → gemma3:4b 순서로 씁니다.
- ollama_vision_model: 화면 보고 팀 찾는 모델 (기본 gemma3:4b)
- whisper_model: 받아쓰기 모델 (auto = 그래픽카드 있으면 large-v3-turbo, 없으면 small)
- fans_from_ai: false면 팬 수를 AI에게 묻지 않고 내장 표만 씀. fans_cache: AI가 답한 팬 수 기록
- chat_mode / chat_intensity: 채팅 분위기와 세기 (메뉴에서 바꿀 수 있음)
- streamer_name: 입력칸에 쓴 내 채팅이 뜨는 이름
- show_captions / caption_preview(auto·on·off) / save_transcript: 해설 자막 설정
- self_review: true면 2분마다 채팅 기록을 AI에게 보내 어색한 문장·닉네임은 빼고
  더 자연스러운 문장·닉네임을 새로 배웁니다. 배운 내용은 fc26_chat_learned.json에 쌓이고
  다음 경기에도 쓰입니다. (처음부터 다시 배우려면 이 파일을 지우세요)

문제가 생기면 fc26_chat.log 파일을 확인하세요.
